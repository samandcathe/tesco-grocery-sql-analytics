Tesco Grocery Analytics – SQL Skills Progression

Project Overview

This project uses the Tesco Grocery 1.0 dataset, containing geographically aggregated grocery purchasing information from Greater London during 2015.

The objective is to develop and demonstrate SQL skills progressively, from basic querying to advanced SQL analysis, while investigating real-world data quality and data engineering challenges.

Technology Stack

Microsoft SQL Server 2019

SQL Server Management Studio (SSMS)

Python

Jupyter Notebook

Git and GitHub

Power BI (future development)

Dataset

12 monthly LSOA CSV files.

51,295 monthly observations.

202 original variables.

4,799 unique geographical areas across the monthly datasets.

SQL Learning Progression

Basic queries – SELECT, TOP, WHERE, ORDER BY.

Aggregate functions – COUNT, SUM, AVG, MIN, MAX.

Grouping and filtering – GROUP BY, HAVING.

Joins – INNER JOIN, LEFT JOIN, FULL OUTER JOIN.

Subqueries and CTEs.

Window functions – RANK, DENSE_RANK, LAG, LEAD.

Data quality assessment.

Data reconciliation.

Advanced analytical SQL.

Key Data Engineering Challenge

The monthly datasets have inconsistent geographical coverage.

4,799 unique areas across the year.

3,407 areas present in all 12 months.

1,392 areas with incomplete monthly coverage.

No duplicate area-month records.

The project investigates these inconsistencies using SQL Server, with the objective of developing reliable data validation and reconciliation processes.

Project Objectives

Develop SQL proficiency from beginner to advanced.

Investigate geographical data inconsistencies.

Build analytical queries for retail and nutritional insights.

Develop practical data engineering skills.

Prepare analytical datasets for Power BI reporting.
